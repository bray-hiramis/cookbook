# COOKBOOK | Recipe Finder

Cookbook is a recipe finder app and utilizes the <strong>themealdb.com API</strong> to search for recipes.

## Features

- V1 features:
      - Search food recipes.
      - Save your favorite recipes.
      - Filter your favorite recipes for faster search.
